# chart-mcp

보고서용 차트 75종을 그리는 MCP 서버입니다. 계정(Claude 채팅)과 업무 에이전트가 같은 코드로 그려 모양이 같습니다.

- 엔진: matplotlib(맑은 고딕, 계정 보고서 색 규칙 — 남색·청록·주황 + 보라·황토·자주)
- 범위: 차트 BOOK·유통·신약개발 카탈로그 106종 중 75종. 막대·꺾은선·원 같은 기본 그래프 28종과 도식 3종은 보고서 변환기(sys-file-builder의 ```chart·```diagram)가 맡습니다.
- 결과: PNG(보고서 본문 폭 16cm·220dpi) + 엑셀 원본(엑셀 차트 46종 · 표 색 단계 8종 · 그림 21종)
- 계산: 카플란-마이어·log-rank·4PL(EC50)·PK(Cmax·AUC·t½)·추세선·관리 한계·상관계수 등은 서버가 계산해 `computed`·`notes`로 돌려줍니다.

## 구조

| 경로 | 내용 |
|---|---|
| `api/mcp.py` | MCP 서버(Vercel 파이썬 함수, ASGI, JSON-RPC 직접 구현) — 게이트 `?k=`, 프로토콜 협상·헤더 검사 |
| `chartkit/api.py` | `draw(type, data, …)` · `to_xlsx(result)` · `list_types()` |
| `chartkit/render/` | 종류별 그리기(category·xy·distribution·matrix·hierarchy·flow·timeline·geo·finance), `legacy/`는 임상·오믹스·특수 차트(원본 엔진) |
| `chartkit/excel.py` | 엑셀 원본 |
| `chartkit/catalog.json` | 75종 목록과 예시 입력 |
| `chartkit/maps/korea_sido.geo.json` | 시·도 경계(17개). 전남광주통합특별시 이름은 광주·전남을 같은 값으로 칠함 |

## 도구

- `list_chart_types(code?, tag?)` — 목록, code를 주면 예시 입력
- `draw_chart(type, data, title?, subtitle?, unit?, options?, output?, include_xlsx?)` — output: `image`(기본) · `base64` · `xlsx`
- `chart_server_status()` — 글꼴·게이트 상태(비밀값 없음)

## 글꼴

맑은 고딕은 저장소에 넣지 않습니다. 서버는 환경변수 `FONT_URL_REGULAR`·`FONT_URL_BOLD`(비공개 주소, `|`로 조각 주소를 이으면 순서대로 받아 붙임)에서 받아 `/tmp`에 둡니다. 없으면 대체 글꼴로 그리고 응답 `notes`에 알립니다.

## 환경변수

| 이름 | 뜻 |
|---|---|
| `MCP_GATE_KEYS` | 허용 게이트키(쉼표 구분) |
| `MCP_GATE_MODE` | `enforce`(차단) · `observe` |
| `FONT_URL_REGULAR`, `FONT_URL_BOLD` | 맑은 고딕 받는 주소 |

## 명령줄(계정 작업 공간)

```bash
pip install -r requirements.txt
python -m chartkit list
python -m chartkit example R-05 > spec.json
python -m chartkit draw spec.json out.png out.xlsx
python tests/smoke.py   # 75종 전부 그리기 + 엑셀
```

### 1.2.6 (2026-11-24)
- 맑은 고딕에 없는 글자는 DejaVu Sans(matplotlib 내장)로 글자 단위 대체 — `font.family = [맑은 고딕, DejaVu Sans]`. 맑은 고딕 원본에도 빼기 기호(U+2212)·≈(U+2248)가 없어, 화산도(R-13) 축 제목 "−log10(보정 p값)"의 빼기 기호가 네모로 나왔다. 사용자 입력 글자에도 같이 적용된다.
- 와플(C-10) 범례: "이름 비율 (값)" → "이름 비율 · N칸". 값이 비율(합 100)일 때 반올림한 값 "(62)"가 실제 칠한 칸(최대 잉여 배분 63칸)과 달라 보였다. 값이 비율이 아니면 값도 함께 쓴다("(1,250) · 63칸").

### 1.2.7 (2026-11-24)
- 엑셀 원본을 Excel에서 열면 "내용에 문제가 있습니다 — 복구" 창이 뜨던 문제: openpyxl 3.1이 차트 XML을 규격과 다르게 써서 생김. `excel.finish`가 모든 차트 XML을 `fix_chart_xml`로 보정한다.
  - 오차막대(평균+오차막대·포레스트·기저치 대비 변화·이상반응): `<minus>`가 `<plus>`보다 먼저 나옴 → 규격 순서(plus → minus)로.
  - 분산형(분산형·궤적·추세선·바이올린·카플란-마이어·대사 산점도 등): 필수 요소 `scatterStyle`이 빠짐 → `lineMarker`를 넣음(선·표식은 계열 서식대로).
- 점검: 75종 예시 통합문서를 SpreadsheetML·DrawingML 스키마로 검증해 남은 오류 0(Excel이 직접 쓰는 꼴인 `t`의 `xml:space`, `ext` 안 c15 요소 여러 개는 스키마 한계로 제외).

### 1.2.8 (2026-11-24)
- 1.2.7 뒤에도 Excel 복구 창이 남아, 스키마로는 통과하지만 Excel이 차트 종류별로 허용하지 않는 값을 `fix_chart_xml`에서 지운다.
  - 데이터 레이블 위치(`dLblPos`): 영역·도넛·방사형·표면형은 지정 불가, 누적 막대는 `outEnd` 불가, 꺾은선·분산형은 t·b·l·r·ctr만. 콤보 '영역 + 막대'(B-16)의 영역 계열이 `t`를 쓰고 있었다.
  - 오차막대 방향(`errDir`): 분산형·거품형에만 남기고 막대·꺾은선(D-15·D-16·R-07·R-10)에서는 뺀다(Excel이 직접 쓰는 꼴과 같게).

### 1.3.0 (2026-11-24)
엑셀 원본 가독성 점검(사용자 Excel 확인 — 75종 전수)에서 나온 것을 고쳤다.
- 범례·제목·축 제목이 그림 위에 겹침: `overlay` 0을 쓴다(없으면 Excel이 겹쳐 그림).
- 숫자 형식이 무시됨("1000"): openpyxl이 `numFmt`의 필수 속성 `sourceLinked`를 빼고 써서 — 0을 넣는다.
- 막대·영역·원 안쪽 라벨 글자색: 칠한 색에 따라 흰색/짙은 회색(파일 변환기 inkOn과 같은 식).
- 투명 보조 계열(폭포·브리지 바닥, 반원 도넛의 숨긴 반원)을 범례·라벨에서 뺀다.
- 꺾은선·분산형 계열은 곡선 끔(`smooth` 0 — 없으면 곡선으로 그려짐), 콤보 영역·채워진 방사형·거품은 반투명.
- 항목 축 글자는 늘 아래·왼쪽(음수 값이 있어도), 순서를 뒤집은 가로 막대의 값 축과 순위 차트의 항목 축은 아래로.
- 누적 꺾은선 라벨 자리(맨 위 계열만 위).
- 날짜 열은 날짜 셀 + 짧은 형식(yyyy.mm / m/d), 항목 축은 글자 축.
- 종류별: 오차막대 항목 이름(1·2·3으로 나오던 것), 포레스트 항목 이름·로그 2 축·기준선 1, 바이올린 숫자 가로축 감춤, 추세선 식 자릿수, 거품 이름 라벨, 사분면 기준선 = 축 교차, 깔때기 값 축 감춤, 풋볼필드 하단·상단 숫자, 주가·풋볼필드 깔끔한 눈금, 폭포 증감 +/− 표시.
